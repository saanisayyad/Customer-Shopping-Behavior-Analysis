# Customer Shopping Behavior Analysis

Customer shopping behavior analysis using **Python, SQL, and Power BI** to uncover purchasing patterns and customer insights.

## Highlights
- Customer and purchase data analysis with Python
- SQL queries for key business questions
- Customer segmentation and purchase behavior analysis
- Interactive Power BI dashboard

## Files
- `customer_shopping_behavior_analysis.ipynb` — Python analysis and EDA
- `customer_behavior_sql_queries.sql` — SQL business analysis queries
- `customer_shopping_behavior.csv` — source dataset
- `customer_shopping_behavior_dashboard.pbix` — Power BI dashboard
- `customer_shopping_behavior_dashboard.pdf` — dashboard export

## Tools
**Python · Pandas · SQL · Power BI**

## Analysis Areas
Revenue, customer segments, subscriptions, discounts, product performance, shipping, ratings, and purchasing patterns.
