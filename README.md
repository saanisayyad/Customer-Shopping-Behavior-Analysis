# Customer Shopping Behavior Analysis

A data analytics project using **Python, SQL, and Power BI** to understand customer purchasing behavior and uncover actionable business insights.

## Project Overview
The project analyzes customer demographics, purchases, product preferences, discounts, subscriptions, shipping methods, ratings, and buying frequency. Python is used for exploratory analysis, SQL for business-focused queries, and Power BI for interactive reporting.

## Key Analysis
- Customer demographics and purchasing patterns
- Revenue by gender and customer segment
- Subscriber vs. non-subscriber spending
- Discount usage and its relationship with purchase behavior
- Product ratings and product performance
- Standard vs. Express shipping purchase behavior
- Customer segmentation into New, Returning, and Loyal customers
- Repeat buyers and subscription behavior
- Top products within each category
- Revenue contribution by age group

## Files
- `customer_shopping_behavior_analysis.ipynb` — Python EDA and analysis
- `customer_behavior_sql_queries.sql` — SQL business analysis queries
- `customer_shopping_behavior.csv` — source dataset
- `customer_shopping_behavior_dashboard.pbix` — Power BI dashboard
- `customer_shopping_behavior_dashboard.pdf` — dashboard export

## Tools & Technologies
**Python · Pandas · SQL · MySQL · Power BI**

## Dataset
The dataset contains 3,900 customer purchase records with fields covering age, gender, item purchased, category, purchase amount, location, season, review rating, subscription status, shipping type, discounts, previous purchases, payment method, and purchase frequency.

## Outcome
The project demonstrates an end-to-end analytics workflow, from exploring raw customer data and answering business questions with SQL to presenting insights through an interactive Power BI dashboard.
